Connect Better Stack Uptime to help Captain check service health and incidents.

## Setup

Create a Better Stack Uptime API token and enter it when installing. The token must have access to the monitors and incidents you want Captain to check.

## Tools

- **List Monitors:** Check monitor status, 20 at a time.
- **Get Monitor:** Check one monitor by ID.
- **List Active Incidents:** Check unresolved incidents, 20 at a time.
- **Get Incident:** Check one incident by ID.

For list tools, start with page 1. The response includes a `pagination.next` link when another page is available.
