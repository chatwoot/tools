# Statuspage

Connect an Atlassian Statuspage to help Captain check service health and incidents.

## Setup

Enter your Statuspage page ID and API key when installing this toolset. The API key must have access to the page.

## Tools

- **List Pages:** Find page IDs available to the API key.
- **List Components:** Check component status.
- **List Unresolved Incidents:** Check current incidents.
- **List Incidents:** Check recent incidents and updates.

For tools with a page number, start with page 1.
