Connect Salesflare to help Captain look up contacts, accounts, and opportunities in your CRM, read internal notes, and log new ones.

## Setup

1. In Salesflare, open **Settings > API keys** and create an API key with the "+" button.
2. Enter the API key when installing.

The key has the same access as the user who created it. Create it from a user who can see the accounts Captain should read.

## Tools

- **Find Contacts by Email:** Find contacts by email address. Returns up to 5 matches with the account ID the other tools need.
- **Find Accounts:** Search accounts by name or domain. Returns up to 5 matches with the account ID.
- **Get Account:** Check an account's website, size, description, owner, tags, and custom fields.
- **List Opportunities:** Check up to 10 opportunities on an account, with stage, value, and close date.
- **List Internal Notes:** Read up to 10 internal notes on an account.
- **Add Internal Note:** Add a plain-text internal note to an account, such as a conversation summary or a follow-up request.

Start with Find Contacts by Email or Find Accounts, then use the account ID with the other tools.

## Notes

- Salesflare links opportunities and internal notes to accounts, not contacts, so most tools take an account ID.
