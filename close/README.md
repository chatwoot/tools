Connect Close to help Captain look up contacts, leads, and opportunities in your CRM, and log notes on leads.

## Setup

Create an API key in Close under **Settings → Developer → API Keys** and enter it when installing. The key has the same access as the user who creates it, so use a user who can only see the leads Captain should see.

## Tools

- **Find Contact by Email:** Find up to 5 contacts by email address. Returns the lead ID the other tools need.
- **Get Lead:** Check a lead's status, description, website, and a link to open it in Close.
- **List Opportunities:** Check the 10 most recent opportunities on a lead, with status, value, confidence, pipeline, and owner.
- **List Notes:** Read the 5 most recent notes on a lead.
- **Add Note:** Add a plain-text note to a lead, such as a conversation summary or a follow-up request.

Start with Find Contact by Email, then use the lead ID with the other tools.

## Notes

- In Close, a lead is the company or account, and contacts, opportunities, and notes all belong to a lead.
- Find Contact by Email uses Close's Advanced Filtering API.
